## 🖥️ Admin Dashboard Features

Once logged in under these credentials, the **👑 Admin Panel** tab will appear in the top-right of the header. The panel provides the following capabilities:

1.  **Participant Score Tracking**: A table showing the FT Number, Full Name, Final Score, Best Decision Streak, Mastery Placement Tier, and Timestamp of every participant who completes the game on this browser session.
2.  **CSV Data Export**: Click the **Export Data** button to download a spreadsheet report (`Strategy_Boardroom_Participants_[Date].csv`) containing all logged candidate performance metrics.
3.  **Reset Leaderboard**: Click the **Reset Leaderboard** button to purge the database and clear the leaderboard, preparing the simulator for a new batch of candidates.
